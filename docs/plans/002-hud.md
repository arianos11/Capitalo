## Architecture notes

### Komunikacja
- HUD jest pure consumer EventBus — **nie czyta** `GameState.money` w `_process`
- `_ready()`: zrób initial snapshot przez `_on_money_changed(GameState.money)` i `_on_ips_changed(EconomyManager.get_total_income_per_second())` → unika frame z pustym labelem
- Subskrypcje:
  - `EventBus.money_changed.connect(_on_money_changed)`
  - `EventBus.income_per_second_changed.connect(_on_ips_changed)`
- Settings button → `EventBus.settings_requested.emit()` (no payload)
- Disconnect w `_exit_tree()` (defensive — autoload signals nie wymagają disconnect przy app close, ale dobry habit)

### NOWY sygnał wymagany w EventBus
```gdscript
## Gracz nacisnął przycisk Settings w HUD.
signal settings_requested
```
Dodać do `scripts/autoload/EventBus.gd` w sekcji `## UI SIGNALS` (linia ~127, obok `screen_tapped`).

### Formatowanie
- Money: `Formatters.format_money(big_num)` → `"$1.23M"`
- IPS: `Formatters.format_money(ips) + "/sec"` → `"$45.6K/sec"`
- Cache last-string per signal — jeśli formatowane string equal ostatniemu, skip `set_text` (microopt, ale Labels redraw cost)

### Layout (portrait 1080x1920)
- Root: `Control` (full-rect anchored top), height 280px
- VBox 1040x200 wewnątrz, offset_left=40, offset_top=80
- HBox top z `Title` (lewa) + `SettingsButton` (prawa, 80x80 square)
- Pod HBox: CashLabel center, font size big (~64)
- Pod cash: IPSLabel center, font size mid (~32)
- SettingsButton placeholder text "⚙" (Unicode cog, font fallback OK), albo "S" jeśli renderer marudzi

### Initial snapshot pattern
```gdscript
func _ready() -> void:
    EventBus.money_changed.connect(_on_money_changed)
    EventBus.income_per_second_changed.connect(_on_ips_changed)
    settings_button.pressed.connect(_on_settings_pressed)
    # initial render — nie czekaj na pierwszy emit
    _on_money_changed(GameState.money)
    _on_ips_changed(EconomyManager.get_total_income_per_second())
```

## Risks

| Risk | Mitigation |
|---|---|
| `Formatters.format_money` może wymagać BigNumber instance (nie float) | Wrap initial GameState.money — już jest BigNumber per architektura |
| Brak m5x7 font → label użyje system default (brzydko ale działa) | OK na M1, polish font swap w M5 |
